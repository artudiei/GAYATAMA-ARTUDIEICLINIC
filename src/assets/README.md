# Folder Assets Gayatama Mind Therapy Clinic

Folder ini disediakan untuk penempatan aset gambar eksternal di masa depan jika ingin menggantikan atau melengkapi sprite generator prosedural canvas.

Format yang didukung:
- Sprite Karakter PNG (16x24 / 32x32)
- Tileset Klinik PNG (48x48 / 64x64)
- Audio SFX & Background Music (WAV, MP3, OGG)
