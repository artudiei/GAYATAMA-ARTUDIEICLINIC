> **Artudiei Clinic** adalah media pembelajaran interaktif berbasis *web role-playing game* bergaya *2D pixel art*. Game ini dirancang untuk melatih keterampilan empati, komunikasi terapeutik, dan pengambilan keputusan klinis berbasis bukti (*Evidence-Based Practice*) melalui skenario konseling psikologi nyata.

## ✨ Fitur Utama

* 🛋️ **Sesi Konseling 3 Fase Berjenjang:** Alur konseling terstruktur mulai dari Fase 1 (*Rasa Aman & Aliansi Terapeutik*), Fase 2 (*Eksplorasi Masalah & Kognitif*), hingga Fase 3 (*Rencana Aksi Mandiri*).
* 🎯 **Integrasi HOTS (Higher-Order Thinking Skills):** Opsi dialog diklasifikasikan ke dalam level kognitif Bloom Revisi (**C4 Analyzing**, **C5 Evaluating**, **C6 Creating**) lengkap dengan rasional klinis.
* 📈 **Dinamika Real-Time (Tension & Rapport):** Setiap pilihan berdampak langsung pada tingkat ketegangan (*Tension*) dan kepercayaan (*Rapport*) klien.
* 📱 **Smartphone Follow-Up Chat:** Fitur pesan teks asinkronus pasca-konseling untuk memantau perkembangan klien di dunia nyata dan memperoleh bonus XP.
* 🪴 **Toko Dekorasi Klinik Biofilik:** Upgrade estetika ruang konseling menggunakan prinsip *Biophilic & Sensory Therapy* (Lampu Garam Himalaya, Akuarium Parasimpatis, Tanaman Lavender, dsb.).
* ☕ **Relaxation Station & Radio Lo-Fi:** Meja seduh teh herbal, observasi *mindfulness* tanaman, dan pemutar musik *chill ambient*.
* 📚 **Papan Referensi Digital:** Ensiklopedia ringkas teori konseling lengkap dengan rujukan sitasi jurnal dan tautan DOI.

## 🧠 Landasan Teori Psikologi

Aplikasi ini mengintegrasikan teori-teori psikologi klinis ternama dunia:

| Teori / Kerangka | Tokoh / Rujukan | Penerapan dalam Game |
| :--- | :--- | :--- |
| **Person-Centered Therapy** | Carl R. Rogers (1957) | Membangun aliansi tanpa syarat (*Unconditional Positive Regard*) & empati mendalam. |
| **Cognitive Behavioral Therapy (CBT)** | Aaron T. Beck & David Clark (1997) | Restrukturisasi kognitif, mengurai distorsi pikiran, dan uji realitas (*Reality Testing*). |
| **Rational Emotive Behavior Therapy (REBT)** | Albert Ellis (1991) | Membongkar keyakinan irasional *demandingness* & ekspektasi perfeksionisme. |
| **Polyvagal Theory & Somatic Grounding** | Stephen W. Porges (2011) | Koregulasi sistem saraf parasimpatis saat klien mengalami badai cemas atau panik. |

## 👥 4 Arketipe Karakter Klien

1. **Si Pencemas & Overthinker (*Anxious / Hypervigilant*)**  
   * *Ciri:* Dominasi pikiran bencana (*catastrophizing*), takut dihakimi sosial, napas pendek & tegang.
   * *Pendekatan:* *Somatic Grounding*, *Active Listening*, dan *Reality Check*.
2. **Si Perfeksionis Rentan (*Vulnerable Perfectionist*)**  
   * *Ciri:* Pola pikir hitam-putih (*All-or-Nothing*), *imposter syndrome*, takut dinilai gagal.
   * *Pendekatan:* *Cognitive Reframing*, *De-catastrophizing*, dan eksplorasi *self-worth*.
3. **Si Defensif & Skeptis (*Defensive / Guarded*)**  
   * *Ciri:* Menutup diri, nada bicara sinis/menyerang, takut disalahkan atau dikritik.
   * *Pendekatan:* *Radical Empathy*, penerimaan tanpa menghakimi, dan konfrontasi lembut.
4. **Si Menghindar & Tertutup (*Avoidant / Detached*)**  
   * *Ciri:* Penyangkalan masalah (*denial*), jawaban singkat satu kata, menarik diri dari sosial.
   * *Pendekatan:* *Pacing*, kehadiran yang sabar, dan eksplorasi minat personal secara bertahap.

## 🎮 Panduan Gameplay & Kontrol

### Kontrol Karakter
* **Desktop (Keyboard):** Gunakan tombol `W, A, S, D` atau `Tombol Panah` untuk berjalan di dalam klinik.
* **Mobile / Tablet:** Gunakan **Virtual Joystick** responsif di pojok kiri bawah layar.
* **Interaksi:** Dekati objek (Sofa Konseling, Meja Teh, Rak Buku, dsb.) lalu klik tombol prompt interaksi yang muncul.

### Alur Sesi Bermain
```
[Masuk Klinik] ──> [Eksplorasi Ruangan] ──> [Duduk di Sofa Konseling]
                                                   │
                                                   ▼
[Follow-Up Chat di HP] ◄── [Papan Evaluasi S-D] ◄── [Dialog Terapeutik 3 Fase]
          │
          ▼
[Toko Dekorasi & Kenaikan Rank Konselor]
```

## 📊 Sistem Penilaian (Grading System)

Setiap akhir sesi, konselor dievaluasi berdasarkan efektivitas klinisnya:

* 🏆 **Grade S (Skor 85–100):** *Maestro Aliansi Terapeutik (Master Clinician)*
* 🥇 **Grade A (Skor 70–84):** *Konselor Empatik & Terampil (Skilled Practitioner)*
* 🥈 **Grade B (Skor 55–69):** *Praktisi Berkemampuan Baik (Competent Helper)*
* 🥉 **Grade C (Skor 40–54):** *Konselor yang Sedang Berkembang (Developing Counselor)*
* ⚠️ **Grade D (Skor < 40):** *Perlu Pendampingan Lanjutan (Supervised Practice)*

## 🛠️ Tech Stack

* **Core Framework:** [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) + Custom Retro Pixel System
* **State Management:** [Zustand](https://github.com/pmndrs/zustand)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)

* **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Cara Menjalankan Proyek (Quick Start)

Pastikan Anda sudah menginstal **Node.js** (versi 18 ke atas) di komputer Anda.

1. **Clone Repositori:**
   ```bash
   git clone https://github.com/username/GAYATAMA-ARTUDIEICLINIC.git
   cd GAYATAMA-ARTUDIEICLINIC
   ```

2. **Instal Dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Server Pengembangan (Dev Server):**
   ```bash
   npm run dev
   ```
   Buka browser di `http://localhost:5173` untuk memainkan game.

4. **Build untuk Produksi:**
   ```bash
   npm run build
   ```
